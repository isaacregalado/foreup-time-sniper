How a drop night goes
  1. Any time before: run a Systems check on the machine you plan to use. It should say passed, with nothing flagged.
  2. Set the plan and arm: pick courses, players and the machine, choose Real booking, then set the auto-arm for about 6:50 pm. Only arm one machine. ForeUp allows one held slot per account.
  3. At 7:00 pm: on the AWS box it books and pays by itself, and ForeUp emails you the confirmation. On this Mac it stops one click short and you click PROCESS TRANSACTION.
  4. If it misses: nothing is charged. It keeps watching for slots that come back when other people’s unpaid holds expire.
